# laby-editor

LABY 에디터의 "AI 편집 화면설계" 프로토타입. 원래는 팀장님이 만든 화면 목업(claude.ai 아티팩트)이었고,
이후 대화를 통해 다음 기능들을 추가로 붙였습니다.

## 실행 방법

빌드 도구 없음. 정적 파일이라 아무 로컬 서버로 열면 됩니다.

```bash
npx serve .
# 또는
python3 -m http.server 8000
```

그 다음 브라우저로 `index.html`을 엽니다 (파일을 더블클릭해서 `file://`로 직접 여는 것도 대부분 동작하지만,
로컬 서버로 여는 걸 권장합니다).

## 파일 구성

- `index.html` — 화면 전체 (마크업 + 스타일 + 로직, 순수 바닐라 JS)
- `data.js` — 자막(cues) · 슬라이드(heads) · AI 프롬프트별 편집안(plans) 목데이터
- `proxy.mp4` — 미리보기용 강의 영상 (연세대 의대 병리학 강의, 52분)

## 지금까지 추가된 기능 (원본 목업 대비)

1. **자막 스크립트에서 구간 추가/제외**
   클릭으로 시작점 지정 → Shift+클릭으로 끝점 지정 → 하단에 뜨는 바에서 "추가" 또는 "제외" 선택.
   편집안이 아직 없으면 "제외" 버튼은 자동 비활성화.

2. **시크바 드래그로 구간 추가**
   시크바를 누른 채 드래그하면 동일한 추가/제외 흐름으로 연결됨 (4px 미만 이동은 기존처럼 단순 클릭=탐색으로 처리).

3. **ON 구간(파란 블록) 리사이즈**
   블록 양 끝에 마우스를 올리면 손잡이가 생기고 드래그해서 길이 조절 가능. 드래그 중 ESC로 원래 크기로 취소.

4. **AI 처리 진행 모달**
   프롬프트 칩을 누르면 바로 결과가 나오지 않고, 처리 단계를 체크리스트로 보여주는 팝업이 뜸
   (`D.plans[key].method`를 "→" 기준으로 쪼개서 단계 문구 생성). 완료되면 "저장 / 취소" 확인 단계로 전환되고,
   **저장을 눌러야만** 실제로 Edit List·시크바에 반영됨.

## 알려진 제한사항 / 다음에 손볼 만한 것

- 구간 추가/리사이즈 시 인접한 같은 상태(ON/OFF) 행을 자동으로 합치지 않음 — Edit List에 잘게 쪼개진 행이 늘어날 수 있음.
- 시크바 드래그로 만든 새 구간과 기존 AI 구간이 겹칠 때 경계 처리는 단순한 자르기(splitAt) 방식이라,
  복잡하게 겹치는 케이스는 검증 필요.
- `proxy.mp4`는 데모용 실제 강의 영상이 통째로 들어있어 용량이 큼(11MB) — 운영에서는 별도 스토리지/CDN에서
  스트리밍하는 구조로 가야 함.
- AI 처리 모달의 진행 시간(현재 단계당 약 1.5초)은 순수 연출용 타이머이며, 실제 백엔드 처리 시간과는 무관.
